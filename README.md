# Cuentas claras · Calculadora de ganancia real

Calculadora para emprendedores del Módulo 2 (Educación financiera) · Ruta 500+ · Fase ELEVA
Secretaría de Desarrollo Económico y Competitividad · Alcaldía de Santa Marta.

- Calcula costo por unidad, ganancia real, margen, ganancia del día y reparto (sueldo, colchón, Unidad Productiva).
- Genera un PDF con los cálculos y los compromisos de la semana como evidencia.
- No envía datos a ningún servidor: todo se calcula en el celular.

Sitio estático (`index.html`), sin compilación. Librerías incluidas en `vendor/` (jsPDF y jspdf-autotable, licencia MIT).
